# anestesiapp.se

The homepage at www.anestesiapp.se and the home of the smaller tools around
it. Förrådet, the supply-ordering PWA ([special-lamp](https://github.com/HarryBMa/special-lamp)),
keeps living on the same domain under each unit's address (`/nks-hh`, `/orto` …).

| Path | What |
|---|---|
| `/` | Homepage: lists the apps. An installed Förrådet PWA that launches here (`/?source=pwa`) is forwarded to its unit. |
| `/blodgas` | Blood gas interpretation: compensation, albumin-corrected anion gap, delta ratio, P/F, A–a gradient. kPa or mmHg. |
| `/lugn` | Patient-facing calm player: generated scenes and sound, breathing guide, optional videos. Swedish/English. |

Everything runs in the browser. No patient data is stored or sent.

## Run it

```bash
bun install
bun run dev        # http://localhost:3001
bun run test       # unit tests (the blood gas logic)
bun run build      # production build to dist/, then type-check
```

## How it's built

Vite + React + TypeScript + Tailwind CSS v4 + TanStack Router: the same
building blocks as special-lamp, without the server rendering.

| Path | Contents |
|---|---|
| `src/routes/` | One file per page. The file name is the URL: `blodgas.tsx` → `/blodgas`. `__root.tsx` is the shared layout. |
| `src/lib/abg.ts` | Blood gas interpretation as pure functions. Read it top to bottom: it follows the stepwise method. |
| `src/lib/abg.test.ts` | Textbook cases the interpreter must get right. Add a case here before changing a rule. |
| `src/lib/soundscape.ts` | Generated ambient sound (Web Audio API). |
| `src/config/videos.ts` | Videos offered in Lugn. Empty until you add some. |
| `src/routes/index.css` | The homepage's own styles. |
| `src/styles.css` | Colour tokens and shared animations used by the tool pages. |

**Adding a tool:** create `src/routes/<name>.tsx` (copy the shape of
`blodgas.tsx`), add a button on the homepage in `src/routes/index.tsx`, and
add the path to the list of routes that special-lamp forwards here (below).
`src/routeTree.gen.ts` is regenerated by the dev server; commit it.

Built assets go to `/hem-assets/` instead of Vite's default `/assets/`,
because Förrådet already uses `/assets/` on the same domain.

## Sharing the domain with Förrådet

Planned setup: the domain stays on the special-lamp Vercel project. This
repo deploys as its own Vercel project, and special-lamp's `vercel.json`
forwards the homepage's paths to it, ahead of its own routes:

```json
{ "src": "/", "dest": "https://<this-project>.vercel.app/" },
{ "src": "/(blodgas|lugn)(/.*)?", "dest": "https://<this-project>.vercel.app/$1$2" },
{ "src": "/(hem-assets/.*|hem-icon\\.svg)", "dest": "https://<this-project>.vercel.app/$1" },
```

Why this way round:

- Nothing about Förrådet moves. Push notifications, installed PWAs,
  Supabase auth redirects and the app-store builds all keep their origin.
- Same origin means the homepage can read Förrådet's remembered unit and
  link straight to it, and the PWA's `/?source=pwa` launch still lands on
  the unit.
- Förrådet's service worker loads pages network-first, so it passes the
  homepage through untouched.
- Rolling back means deleting three lines.

Before that change goes live, special-lamp should also treat `blodgas`,
`lugn` and `hem-assets` as reserved, so no unit can take those slugs. No
current unit uses them.
